# v6.2 构建链说明

## 目标

v6.2 将博客的增强功能按“源码 → 构建 → site”统一管理。

### 已接入模块

- `reading.js`：文章阅读进度
- `share.js`：原生分享与链接复制
- `images.js`：图片懒加载与 Lightbox
- `seo.js`：文章结构化数据
- `author.json`：作者元数据
- Mermaid / KaTeX / Highlight.js：高级内容渲染

## 发布原则

不要手工编辑 `site/` 中的生成文件。修改 `posts/`、模板或构建脚本后，由 GitHub Actions 重新构建。
